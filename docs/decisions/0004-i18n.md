# 0004 Internationalization (Traditional Chinese + English)

- Status: accepted
- Date: 2026-10-30

## Context

CLAUDE.md originally listed internationalization as a non-goal. The maintainer expects English-speaking users who can't read a Traditional Chinese Settings window. Chinese strings aren't only in the Settings window; they are spread across the widget (「2時13分」, 「滿 · 20:15 重置」, 「未登入」), the hover card, the tray, notifications, and the error messages raised by providers.

## Decision

- Support Traditional Chinese and English, and **switch the whole UI together** (not just the Settings window)
- The `language` setting defaults to `"system"`, following the Windows display language (`zh*` → Traditional Chinese, anything else → English); Settings can pin a language, applied immediately
- Translation tables are plain Python dicts in `core/i18n.py`, looked up with `t(lang, key, **params)`
- `PollError` gains a `reason` (`ErrReason`), and the UI shows that reason in the current language; `message` is for logs only
- `source_label` becomes a code (`desktop`, `cli`, `codex_cli`) translated by the UI
- Logs and `diagnose` are not translated

## Reasons

- Following Windows by default: English users see English on first launch, without hunting for a language option in a UI they can't read; consistent with how the theme works
- Only two languages and about 150 strings: plain dicts need no extra tools or compile step, nothing extra to package, and pyright can check them; tests guarantee both languages have the same keys and `{params}`
- Living in `core`: the tables are pure data with no I/O, usable from both `ui` and `diagnose`, and testable on Linux CI
- Errors as codes rather than strings: providers don't need to know the current language, and translation stays in the UI layer

## Alternatives

- Qt Linguist (`tr()` + .ts/.qm): viewmodel and core don't depend on Qt, so it doesn't fit; it also needs an lupdate/lrelease workflow
- gettext (.po/.mo): the industry standard, but its advantages don't matter for two languages, and it adds compiling and packaging
- Translating only the Settings window: English users would still see 「2時13分」 on the widget, an inconsistent experience
